# 设计规范

## 视觉方向

采用极简原生 macOS 风格。界面安静、清晰、适合每天重复使用，不使用营销式大标题、装饰性渐变或多层卡片。

## 布局

- 应用入口位于 macOS 顶部菜单栏，点击书本图标展开学习面板。
- 使用 `NavigationSplitView` 构建侧边栏与内容区。
- 主页面为今日学习、已学会、生词本和设置。
- “已学会”和“生词本”在侧边栏标题右侧显示实时总数徽标。
- 内容区最大阅读宽度约 760 点，长文本保持舒适行长。
- 卡片圆角不超过 8 点，避免卡片嵌套。
- 菜单栏学习面板尺寸为 900×620。

## 色彩与字体

- 优先使用系统语义色，自动适配浅色和深色模式。
- 橘色作为应用主题色，用于侧边栏选中态、主要操作、标题、进度条、卡片边框、语法标签、例句强调线和生词本；绿色仅表示已学会。
- 英文核心词使用清晰的衬线字体，中文说明使用系统字体。
- 不使用随窗口宽度连续缩放的字号。

## 交互

- 发音按钮使用扬声器图标，并提供工具提示和 VoiceOver 标签。
- 当前朗读内容显示停止状态，同一时间只播放一段语音。
- 状态按钮必须显示当前状态，切换后立即保存。
- 搜索使用系统搜索框；空状态说明下一步可执行操作。
- 所有按钮支持键盘聚焦，重要操作具有明确文本或辅助标签。
- 侧边栏底部提供“退出英语学习助手”，避免隐藏 Dock 后缺少退出入口。
