# 测试与验收

## 自动化测试

- 内容仓库确实提供 300 个词汇和 60 条语法。
- 每个词汇至少有两个相关短语和一个用法说明。
- 100 个核心词均有独立场景例句，不包含旧版通用模板句。
- 每日抽取不包含已有学习状态的内容。
- 同一天不重复生成，跨自然日可生成新内容。
- 默认设置为 5 个单词、1 条语法、上午 9:30。
- 状态切换会更新当前状态并追加历史事件。

## 手工验收

- 启动后只显示顶部菜单栏图标，不显示 Dock 图标。
- 点击菜单栏图标可展开或收起 900×620 学习面板。
- 四个主页面可从侧边栏进入。
- 侧边栏“已学会”和“生词本”显示各自实时总数，状态变化后数字同步更新。
- 单词、短语、单词例句和语法例句均可朗读和停止。
- 搜索可以匹配英文、中文释义和语法标题。
- 在“今日学习”点击“学会了”后，卡片立即移除并出现在“已学会”类目。
- 在“今日学习”点击“加入生词本”后，卡片立即移除并出现在“生词本”类目。
- 在“已学会”类目点击“取消已学会”后，条目从列表移除并恢复为未标记状态。
- 修改通知时间或数量后重启应用仍保留。
- 拒绝通知授权不会影响学习功能。
- 浅色、深色模式和最小窗口尺寸下无文字遮挡。
- VoiceOver 能读出发音和状态按钮的用途。
- 侧边栏“退出英语学习助手”可以结束应用。
